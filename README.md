# 360 Mobile Detailing & Auto Spa website

This is a complete mobile-friendly static website.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `360-detailing-site`.
2. Upload every file and the `assets` folder from this package.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a temporary website address.

## Connect the Squarespace domain
After GitHub Pages is working, add `360detailingautospa.com` under **Settings → Pages → Custom domain**. GitHub will show the DNS records to add in Squarespace.

## Important edits before publishing
- Replace gallery placeholders with your own photos.
- Add your exact Facebook page link when available.
- Confirm all services and wording.
- The quote form opens the visitor's email app; it does not store submissions.

## Included custom-domain file
The package includes a `CNAME` file for `360detailingautospa.com`. Keep that file in the root of the repository.
